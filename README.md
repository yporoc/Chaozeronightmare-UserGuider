## 适用于国际服PC客户端 加速补丁和繁转简社区维护版

https://github.com/yporoc/ChaosZeroNightmare-Toolkit-Extra

### 常见问题：

**1 为什么提示找不到datapack，未找到数据分卷，未找到繁中语言包**

请前往GitHub仓库下载最新release使用繁转简功能，注意其版本号为2.0.5（10.21release），官方在更新中更改了游戏客户端资源的分卷格式，旧版本的繁转简已不再适用，但旧版本的加速功能仍可正常使用，只比社区维护版略微少一些功能，感谢原作者9S做出的独创性工作

**2 为什么进入游戏之后会出现“更新失败”或“uncheater@xxxxxxxxxxxxxxxx”此类弹窗，且按任何按键或点击任何位置后游戏都会闪退**

这是游戏内置反作弊的一个网络会话，当其无法连接海外CDN或网络状态出现剧烈变化时会出现此弹窗，解决办法，临时缓解方法：按F8执行进程内重启，再次进入游戏大厅后应当不会再出现此弹窗，如若再次出现请重复此步骤；彻底解决方法：使用下方移除反作弊的项目彻底移除游戏内置反作弊，此后游戏将永远不会出现此弹窗

**3 为什么我在灵光一闪界面会丢失卡牌画面，看不到闪光特效后待选三张卡片的任何卡面信息**

这是倍速和跳过动画功能导致的渲染问题，当前版本游戏支持键盘选择，如果您不在意闪光信息可使用键盘任意选择，如果需要看清卡片信息请按F8执行进程内重启，重启后您的倍速和跳过的设置状态会被重置复位，此时您可以正常看到卡片信息并做出选择

**4 为什么我点击任何可交互UI界面后倍速会突然闪一下变成1X**

这是倍速状态下对点击的长按短按判定保护，如果不进行保护，倍速状态短按点击卡牌时会直接判定为长按，难以正常选择，当然您可以也手动调整至1倍速进行选择

**5 为什么开启倍速后游戏自动战斗后有时无法正常选择要被丢弃或选择抽取的卡牌**

时序问题，游戏自动战斗的点击在加速状态下未被正常识别和触发，这个问题在倍速越高的状态下越显著，当前无修复计划，您可以为项目贡献修复方案，提交相关PR前请先发起issue进行讨论，或直接fork到您的仓库进行二次开发

**6 为什么补丁完成后点击确定替换无法成功替换**

你需要为补丁程序提供管理员进程身份的运行许可，右上角按钮会显示当前管理员请求状态，点击可自动申请UAC提权，如果您未开启UAC，请您使用管理员账户启动补丁程序，或者您手动自行替换

**7 加速会不会封号**

严格来说服务端检查倍速状态下客户端的网络交互行为可以识别到，但如果您移除了反作弊的确无需担心反作弊问题，开发者从未强迫任何人使用任何项目，使用任何项目是您主动做出的选择，  
此行为导致的风险请您自行承担

**8 为什么找不到游戏路径**

本项目启动时会读取注册表中游戏的注册表项，用以定位正确的游戏路径，您未以管理员运行时无法执行此行为，您可以手动选择，如果您注册表项的游戏路径都不正确，无法想象您是如何正常启动并进入游戏的！

**9 为什么打开补丁程序Windows会出现安全保护弹窗**

双击exe后会自动执行读取注册表项，外部未知应用执行此操作会触发安全保护，请您放心放行，本项目完全开源接受任何审查，甚至比您的Windows操作系统更安全！

https://github.com/yporoc/ChaosZeroNightmareLauncher-Lite

### 常见问题：

**1 为什么点击获取离线信息无法正常获取**

您必须以管理员身份运行启动器主程序，启动器需要读取很多不同位置的信息以初始化，这些离线信息被用于构造命名管道服务的环境变量键值信息，必须提供给游戏进程

**2 请详细阅读启动器内置的使用说明，启动器只模仿执行拉起游戏进程前的STOVE客户端的行为，对启动后的游戏进程无任何更改，请勿错误归因**

**3 实现原理：STOVE客户端内置地区检测，拒绝为中国大陆IP提供游戏启动服务，本项目直接使用你的账号信息与游戏私有API进行网络交互，任何网络交互行为都会原样打印在控制台日志中，您可以完整看到启动的所有流程，使用的私有API并未主动拒绝中国大陆IP，少数地区如无法连接海外API请更改右下角的网络连接设置，使用系统代理，此时启动器所有流量会主动跟随系统代理路由到您的代理客户端，官方STOVE客户端不会主动跟随系统代理，此时您可以使用TUN或WFP等代理实现进行流量路由**

**4 直连私有API不等于完全无需代理启动游戏，启动器只提供登录和拉起进程，游戏进程内还有海外CDN的补丁校验，然而官方在AWS的CloudFront配置里主动设置了拒绝中国大陆IP，您可能需要配合下方的绕过外CDN补丁校验项目使用以实现完整的免代理启动和进入游戏**

## 适用于安卓Google Play原版国际服apk的zygisk模块，提供更强大更灵活的功能和更舒适的gui

https://github.com/yporoc/CZNSpeed-ZygiskNext

### 常见问题：

**1 作者使用KernelSU和Zygisk Next，请尽可能使用KSU或完整保留KernelSU原版功能的下游分支的内核Root管理器，将会不断适配和跟进Zygisk Next版本更新**

**2 能不能做成LSPosed模块**

当然可以，但实际上本项目实现的核心逻辑是基于对游戏引擎的Native Hook，游戏引擎位于Native层，LSPosed适合对Java层进行更多Hook的项目，Java层对本游戏而言只是基础设施，无法影响游戏逻辑和游戏引擎，套一个繁复的LSPosed模块的壳却完全不执行任何对Java层的Hook，转而只调用Zygisk的API是多此一举的

**3 对安卓跨版本和游戏版本更新的兼容性和适配性**

具体来说，本项目使用的是GOT Hook，而非Inline Hook，通过Zygisk向游戏进程内注入一个.so，解析ELF后扫描并定位若干个游戏引擎的GOT特征槽位，找到后在游戏引擎加载资源处布置钩子，引擎走到此位置时会主动加载我们加速JS逻辑，成功注入或找不到目标超时后模块就会停止任何行为并保持静默，对注入目标进程已经做了多层过滤，但仍请您使用白名单注入模式，对非游戏应用开启内核级卸载模块和对Webview卸载模块

**4 支持且可以成功注入国服，国服的GOT槽位特征与国际服一致，但国服游戏存在ACE，虽然无法拦截模块的注入，但其保护和检测逻辑真实生效，请您自行处理，本模块不做任何处理**
